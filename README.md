Market Tracer - Pro Terminal
Market Tracer es una plataforma web y de escritorio multiplataforma orientada al análisis bursátil y de criptomonedas en tiempo real. Combina un motor técnico en el backend para el procesamiento de indicadores con una interfaz tipo terminal financiera moderna, rápida y bilingüe.

Tecnologías Utilizadas
Backend:

Python 3

FastAPI: Framework de alto rendimiento para la creación de endpoints de análisis.

Uvicorn: Servidor ASGI en producción.

yfinance: Módulo de extracción de datos en vivo para acciones tradicionales del Nasdaq y mercados globales.

Requests: Gestión de solicitudes HTTP hacia proveedores de datos.

Frontend:

HTML5 y JavaScript Moderno: Implementación reactiva con React 18 y Babel mediante CDN.

Tailwind CSS: Diseño responsivo, minimalista y adaptado a modo oscuro (dark theme).

TradingView Widgets: Integración de gráficos de velas japonesas interactivos, RSI y herramientas de trazado.

Web Audio API: Generación de alertas sonoras dinámicas sin librerías externas.

LocalStorage: Persistencia local para el saldo virtual, historial de operaciones y favoritos.

Funcionalidades Principales
Análisis de Mercados Múltiples: Monitoreo en tiempo real de criptomonedas en mercado Spot y principales acciones del Nasdaq.

Ranking Técnico e Indicadores: Clasificación automática basada en cálculo ponderado de RSI (14 periodos) y medias móviles.

Simulador de Paper Trading: Ejecución de órdenes virtuales sin riesgo con un saldo inicial de $10,000 USDT para probar estrategias.

Alertas Exclusivas para Favoritos: Notificaciones flotantes (Toasts) y alertas sonoras restringidas únicamente a los activos agregados a la lista de seguimiento (Watchlist).

Guía Interactiva y Splash Screen: Pantalla de carga estilizada al iniciar y un tour interactivo paso a paso para nuevos usuarios.

Soporte Multiidioma: Cambio fluido en tiempo real entre Español e Inglés.

Market Tracer - Pro Terminal
Market Tracer is a cross-platform web and desktop application designed for real-time cryptocurrency and stock market analysis. It combines a technical backend engine for indicator processing with a modern, fast, and bilingual financial terminal interface.

Tech Stack
Backend:

Python 3

FastAPI: High-performance framework for building analysis endpoints.

Uvicorn: Production-ready ASGI server.

yfinance: Live market data fetcher for Nasdaq stocks and global assets.

Requests: HTTP request handler for external data feeds.

Frontend:

HTML5 and Modern JavaScript: Reactive interface built with React 18 and Babel via CDN.

Tailwind CSS: Responsive, minimalist dark-mode design.

TradingView Widgets: Interactive candlestick charts with built-in RSI and technical tools.

Web Audio API: Dynamic audio alert generation without external libraries.

LocalStorage: Local persistence for virtual trading balances, trade history, and watchlists.

Key Features
Multi-Market Scanning: Real-time tracking of Spot Cryptocurrencies and top Nasdaq Stocks.

Technical Ranking and Scores: Automated ranking system calculated using RSI (14 periods) and moving averages.

Paper Trading Simulator: Risk-free virtual trading execution backed by a virtual $10,000 USDT balance.

Watchlist-Exclusive Alerts: Toast notifications and audio alerts triggered only for user-starred assets.

Interactive Tour and Splash Screen: Initial loading splash screen paired with a step-by-step onboarding guide.

Multilingual Support: Instant toggle between English and Spanish across the entire application.
